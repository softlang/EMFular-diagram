Drag and drop

Angular has no built in drag and drop for svg elements - instead, we must use mouse down to discover the selection of an element, then move it while the mouse moves and finally stop the drag when the mouse moves up again. However, we need to make sure that we can also detect a click and a double-click and that these events do neither interfere with each other nor with drag and drop. Hence, this section is concerned with all types of mouse events.

Dragging

There is an explicit draggable svg component, it is supposed to be extended by an own svg component with an own template. The base component makes sure that drag events are correctly reported to the SVGAccessService.

As for the our extending component, its template shows a small rectangle that we can drag.
