Provided SVG-Primitives

Our SVG components are built around two concepts, a Point2D and a BoundingBox.

We want to offer some basic functionality for those who only require basic building blocks like rectangles, triangles and text. Arrows can be seen as further primitives, however, their complex structure justifies that we handle them separately. Defining an own SVG-component is simple, just refer to a normal SVG guide to create your template.

Triangles

Triangles are defined over three input Point2Ds, A, B, C, and a color string. For any other free position shapes, you can just generalize this model.

Rectangles

The rectangle component guarantees orthogonality. If not rotated, it has sides parallel to the axes, just like a bounding box, that it consumes as input. The second input is to define a color (otherwise black). This color becomes an inner svg property and is hence exported on svg download. You can also rotate the example rectangle, but we control the rotation by external style, hence exporting it to an svg would not transport the rotation.
